# ONNX Runtime C++ Helper 单元测试

## 测试概述

本项目包含完整的单元测试套件，使用真实的ONNX模型验证所有功能。

## 测试模型

### 1. MNIST手写数字识别模型

- **文件**: `models/mnist-12.onnx`
- **大小**: ~26 KB
- **输入**: `(1, 1, 28, 28)` - 灰度图像
- **输出**: `(1, 10)` - 10个数字的分类得分
- **来源**: [Hugging Face ONNX Model Zoo](https://huggingface.co/onnxmodelzoo/mnist-12)

### 2. ResNet18图像分类模型

- **文件**: `models/resnet18-v1-7.onnx`
- **大小**: ~45 MB
- **输入**: `(batch, 3, 224, 224)` - RGB图像（支持动态批量大小）
- **输出**: `(batch, 1000)` - ImageNet 1000类分类
- **来源**: [ONNX Model Zoo](https://github.com/onnx/models)

## 运行测试

### 下载模型

模型会自动下载到 `models/` 目录。如果需要手动下载：

```bash
# 创建models目录
mkdir models

# 下载MNIST模型
powershell -Command "Invoke-WebRequest -Uri 'https://huggingface.co/onnxmodelzoo/mnist-12/resolve/main/mnist-12.onnx' -OutFile 'models\mnist-12.onnx'"

# 下载ResNet18模型
powershell -Command "Invoke-WebRequest -Uri 'https://github.com/onnx/models/raw/main/validated/vision/classification/resnet/model/resnet18-v1-7.onnx' -OutFile 'models\resnet18-v1-7.onnx'"
```

### 编译测试

```bash
# 配置项目（x86）
cmake -B build_x86 -S . -A Win32

# 编译单元测试
cmake --build build_x86 --config Release --target unit_tests
```

### 运行测试

```bash
# 通过 CTest 运行所有已注册测试（推荐）
ctest --test-dir build --output-on-failure -V

# 或直接运行单元测试可执行文件（需在项目根目录执行以便查找 models/）
./build/unit_tests                  # Linux
.\build_x86\Release\unit_tests.exe  # Windows
```

## 添加新测试

要添加新的测试用例，在 `unit_tests.cpp` 中创建新的测试函数：

```cpp
void TestNewFeature(TestStats& stats) {
    std::cout << "\n========== 测试N：新功能 ==========" << std::endl;
    
    try {
        // 测试代码
        stats.Pass("测试项名称");
    } catch (const std::exception& e) {
        stats.Fail("测试项名称", std::string("异常: ") + e.what());
    }
}
```

然后在 `main()` 函数中调用：

```cpp
int main() {
    TestStats stats;
    
    TestMNIST(stats);
    TestResNet18(stats);
    TestDataTypes(stats);
    TestBatchProcessing(stats);
    TestErrorHandling(stats);
    TestNewFeature(stats);  // 添加新测试
    
    stats.PrintSummary();
    return (stats.failed == 0) ? 0 : 1;
}
```

## 持续集成

单元测试可以集成到CI/CD流程中：

```yaml
# GitHub Actions示例
- name: Run Unit Tests
  run: |
    cmake -B build -S . -A Win32
    cmake --build build --config Release --target unit_tests
    .\build\Release\unit_tests.exe
```

测试失败时会返回非零退出码，自动中断CI流程。

## 注意事项

1. **模型文件**: 确保 `models/` 目录包含所需的ONNX模型文件
2. **内存**: ResNet18模型较大，需要足够内存
3. **架构**: 当前测试使用x86架构，如需x64请修改CMake配置
4. **执行提供程序**: 默认使用CPU，如需GPU请安装相应驱动

## 故障排除

### 模型文件不存在

```
提示: ResNet18模型不存在，跳过批量处理测试
```

**解决**: 运行上述下载命令获取模型文件

### 内存不足

```
异常: ONNX Runtime推理失败: Out of memory
```

**解决**: 减小批量大小或使用更小的模型

### 形状不匹配

```
异常: 数据大小与形状不匹配
```

**解决**: 检查输入数据大小是否与声明的形状一致
